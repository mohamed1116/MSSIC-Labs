## Overview

This repository documents my coursework for **M115 — AI & Intelligent Systems**, part of the Master's program in Intelligent Systems and Cyber Defense (MSSIC) at ENSIASD Taroudant, Ibn Zohr University.

It serves as a living record of labs, exercises, and assignments completed throughout the academic year. Each piece of work is self-contained in its own directory with the notebook, dataset references, and any supporting files.

---

## Scope

The module sits at the intersection of machine learning and cybersecurity engineering. Work in this repository covers:

- Security-oriented exploratory data analysis
- Leakage-safe supervised learning pipelines
- Multi-model evaluation and selection
- Explainable AI with SHAP (linear and tree-based models)
- Cost-aware threshold optimization for SOC environments
- Static malware analysis and PE file forensics
- Phishing and URL-based threat detection
